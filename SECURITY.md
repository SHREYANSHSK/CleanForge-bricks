# Security Policy

## Supported Versions

CleanForge Bricks is currently under active development. We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please bring it to our attention right away!

### Please DO:

1. Email us at [maintainer's email] with the details of the vulnerability
2. Provide steps to reproduce the vulnerability
3. Wait for us to respond before disclosing the vulnerability publicly

### Please DO NOT:

1. Open a public issue about the vulnerability
2. Disclose the vulnerability publicly before we've had a chance to address it
3. Test the vulnerability on production systems

## Security Best Practices

When using CleanForge Bricks, follow these security best practices:

1. Keep your dependencies up to date
2. Use secure storage for sensitive data
3. Implement proper authentication and authorization
4. Follow Flutter security guidelines
5. Regularly update your Flutter SDK

## Communication

We will acknowledge receipt of your vulnerability report within 48 hours and will send you regular updates about our progress.

## Policy Updates

This policy may change over time. We will notify users of any changes by updating this document.
