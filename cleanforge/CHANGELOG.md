# Change Log

All notable changes to the "cleanforge" brick will be documented in this file.

## [1.0.0] - 2025-10-20

### Added
- Initial release of cleanforge brick
- Complete project structure generation with Clean Architecture
- GetX integration with state management setup
- Theme management system with light/dark mode support
- Built-in error handling and logging system
- Network layer with REST client configuration
- Local storage integration
- Base widgets and utilities
- Environment configuration
- Route management system

### Features
- Automatic project scaffolding
- Core utilities and helpers
- Theme system with customizable components
- Network layer with interceptors
- Local storage management
- Error handling and logging
- Navigation system

### Dependencies
- GetX for state management
- Dio for network requests
- Hive for local storage
- Logger for debugging

- Path resolution issues on Windows
- Template variable interpolation
- Missing pubspec dependencies

### Changed
- Improved error messages
- Updated documentation
- Enhanced code generation templates
